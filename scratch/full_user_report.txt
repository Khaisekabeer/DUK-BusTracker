1. Architecture Overview
The backend is a monolithic FastAPI application (mega_gateway.py) that runs 7 microservices in a single uvicorn process. Routing is done by URL path prefix:

Path Prefix	Service	Auth Required
/api/v1/auth/*	auth-service	❌ (register/verify) ✅ (logout, device-token, preferences)
/api/v1/stops, /api/v1/routes, /api/v1/latest, /api/v1/trip_state, /api/v1/eta	tracking-service	❌ Public (read-only)
/api/v1/ws/bus	realtime-gateway	✅ JWT via query param
/api/v1/notifications/*	notification-api	✅ JWT Bearer
/api/v1/suggestion	notification-api	✅ JWT Bearer
/api/v1/admin/*	admin-service	✅ Admin JWT / X-Admin-Token
/api/v1/gps/*, /api/v1/ws/device	gps-ingestion	✅ GPS_API_KEY (hardware only)
/api/v1/ml/*	eta-ml-service	Internal only
Base URL: https://<DOMAIN>/api/v1/
